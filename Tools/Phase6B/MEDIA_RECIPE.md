# Phase 6B deterministic media recipe
Audio: 48,000 Hz mono signed 16-bit PCM WAV; deterministic oscillators + seeded pseudo-random noise; cue-specific envelopes; conservative peak normalization; no limiter/maximizer and no external media input.
VFX masks: 64x64 32-bit uncompressed TGA, white RGB with generated alpha; radial SoftDisc, anisotropic Streak, annular Ring, deterministic seeded Noise.
