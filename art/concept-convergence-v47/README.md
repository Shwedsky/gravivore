# V47 editable production sources

Original GRAVIVORE manufactured actor geometry, deployment machinery and fitted deck panels. These are project-owned sources generated by `Tools/concept-convergence-v47/build_actors.py` and `build_facilities.py`.

The seven actor files retain the existing project-authored rest skeletons and animation actions from tracked `art/visual-replacement-v3/`. Hidden editable part collections and three joined runtime LODs are retained. Runtime model paths and GUIDs stay unchanged; imported whole presentation prefabs preserve the rich V46 atlas materials. No S15 Body/Accent/Dark consolidation is applied to these assets.

Facility sources retain separate manufactured parts. Their exports are under `Assets/_Game/Content/ConceptConvergenceV47/Models/`, with reviewed prefabs under `Prefabs/`. All nine facility placements use existing encounter origins and collision proxies. The open bridges and tooling are suspended behind the spawn apron; grounded console and upright forms occupy existing solid footprints. Floor panels are flush presentation meshes over the existing collision plane.

The V46 base-color, normal, metallic/smoothness, occlusion and emission textures remain the runtime surface source. The deck adds a material instance with a darker neutral multiplier and reduced normal amplitude; it adds no texture payload.

No new external assets, raw donor cache, paid dependency, restricted Asset Store payload or game-derived art was used. The owner concept was inspected as reference only. Current G-0 remains bipedal. Triangle reduction and LODs are optimization tools; the target is premium industrial hard-surface sci-fi.

One-off V47 validation and visual evidence belongs under `docs/history/implementation-passes/chapter01-visual-replacement-v3/v47/` and is non-authoritative.
