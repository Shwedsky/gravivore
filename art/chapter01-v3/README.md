# Chapter 01 V3 original asset sources

These meshes and rigs were authored for this repository with the project-owned Blender helpers. The owner's supplied GRAVIVORE board is visual inspiration; no geometry, textures, audio or game assets were extracted from it or another game. No additional third-party assets, paid services or packages are used.

Rebuild with Blender 5.2 LTS: `blender --background --python Tools/chapter01-v3/build_assets.py`, then run `Tools/chapter01-v3/run_unity.ps1 -Action Integrate` with Unity 6000.3.0f1. FBX runtime assets reuse the existing original Fidelity industrial atlas. Compressed `.blend` sources remain editable.

Custodian V3: six mechanical support limbs, layered command shell, recessed cannon, exposed dorsal red reactor, rigid mechanical skin and three LODs. G-0's approved bipedal models are retained; Emitter M-0 adds a separate right-manipulator hardpoint mesh.

Broken perimeter segments, conduit trenches and collapsed hull pieces contain no gameplay colliders. They enrich existing safe traversal and the space beyond the perimeter. Runtime authority remains in the existing world configuration.
