# Cutting Floor and industrial transfer — editable original source

`CuttingFloorAndTransfer.blend` contains independently editable modeled parts before runtime material/culling consolidation. `Tools/connected-concept-sectors/author.py` produces it and two unit-scale runtime FBXs. The shared engineering helpers preserve physical metre UVs, but the heavy press/shear/feeding topology is a different construction from Capacitor Field's vessels and banks.

New geometry is original project work. It references existing CF surface vocabulary plus original fabrication maps. No new third-party model, texture download or vendor script is used. The clipped retained service-network meshes keep all outside faces/native UVs/materials of the already promoted R1 network; its original source FBX remains unchanged and keeps its existing provenance/notices.

Original static HDR lighting environment is generated by the Unity authoring builder and saved as a small cubemap. It is not a photographed environment, realtime probe or claimed light bake.
