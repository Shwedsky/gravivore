# ART SPIKE V3 license scope

**SHARE-ALIKE CHARACTER DEPENDENCY: NO**

The selected V3 G-0/Cutter pipeline contains original project-authored proxy geometry, shared project materials, common Unity primitive/ring elements, and CC0 Blue Metal Plate textures. None of the current prefabs, comparison scene, mesh assets, animation clip or ten newly generated PNGs uses Julius meshes. The raw Julius directory and metadata have been removed. Ordinary Git history preserves the earlier V2 content and its original CC BY-SA 3.0 obligations; this document does not relicense historical files or images.

- Changes: original map bytes unchanged; project-owned URP material tints; separate derived AO and metallic/smoothness maps under Proxy/Textures. Linear ARM conversion preserves AO/metal and converts roughness to smoothness. No source preview render, site logo or website text is reproduced.

Existing supporting scenery remains Kenney Factory Kit 3.0 / Modular Space Kit 1.0, CC0. Exact unchanged subsets and bundled notices are listed in ThirdPartyNotices.md and the manifest.

Project-authored geometry/code/materials/compositions/renders retain the repository's applicable terms; no new blanket license for the whole repository is asserted. There is no external share-alike adaptation in the selected V3 work.
