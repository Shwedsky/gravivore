## Use in later production sessions

Open and inspect the exact PNG before authoring actor art. Verify its hash. If it is absent, stop and report missing visual authority; do not generate a replacement, fall back to an old enemy board, or treat text alone as visual certification. If the hash changes unexpectedly, stop and establish the owner-authorized image revision before proceeding.

Use the main actor panel, alternate views, gameplay/top views and scale strip together. UI number badges and palette swatches are not actor paint instructions. Where a depicted detail conflicts with a newer owner correction, preserve the image and document the correction in text. Do not resolve an ambiguity by inventing anatomy, weapons, colors or locomotion classes.

Donors may supply rigs, animation or selected mechanical parts. They never define the actor silhouette. Review anatomy against the PNG before donor selection, after geometry adaptation and in the actual portrait gameplay camera. Final acceptance requires the Android device result; donor screenshots and Blender beauty renders cannot substitute for it.
