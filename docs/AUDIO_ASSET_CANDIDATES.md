# GRAVIVORE — Audio Asset Candidates

Status: **RESEARCH COMPLETE / BINARY INTAKE PENDING**  
Checked: **2026-10-04**

Selection rule: only candidates with explicit commercial/modification/redistribution-compatible licensing are promoted. For this pass, the selected baseline is CC0. No NC, SA, ripped audio, franchise audio, login-only source, or ambiguous "free" listing is selected.

## Quality grades

- **A** — strong enough to audition for external-test baseline.
- **B** — usable source/layer or prototype fallback; likely needs editing/layering.
- **C** — reference/reject for GRAVIVORE.

Important: grades below are based on public metadata/style fit. Binary waveform inspection was not possible in this autonomous lane, so no file is marked production-final until local intake verifies format, sample rate, bit depth, channels, clipping, silence and tail.
