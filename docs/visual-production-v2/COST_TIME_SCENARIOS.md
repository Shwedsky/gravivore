# Cost / Time Scenarios — First Visual Slice

Assumptions: one competent Blender generalist, approved concept already available, no major gameplay redesign, scope limited to G-0 Tier 0 + Scout + Cutter + Magnetar + one ~15×20 m combat area + gate + reactor + 4–6 props + material set. Ranges reflect uncertainty in donor-source quality and revision count.

## 1. ECONOMY

Production mix:
- Quaternius CC0 environment backbone;
- Sketchfab CC BY donor candidates where source files prove usable;
- Poly Haven CC0 materials;
- optional one-month Meshy/Tripo/Rodin subscription;
- custom Blender work focused on G-0, Cutter blades, Magnetar torso, reactor.

Direct spend: **$0–$40** typical; up to ~$60 if one month of AI + small itch.io prop pack is purchased.

Manual work: **12–22 focused artist-days**.

Expected visual quality: **B / B+** if the custom passes are executed well; risk of donor/stylized look remains highest in environment and minor enemies.

Delivery risk: **medium-high**. Main uncertainty is whether free donor source topology/rigs are worth salvaging.

Time to first playable visual slice: **~2.5–5 working weeks** for one person at full-time equivalent effort; longer in spare-time cadence.

## 2. BALANCED — RECOMMENDED

Production mix:
- one coherent paid industrial environment family after FBX/Blend/license verification;
- inexpensive coherent secondary props pack;
- custom/hybrid G-0;
- best inspected donor for Scout;
- donor chassis + custom front end for Cutter;
- donor limbs/joints + custom Magnetar body;
- custom reactor/gate hero treatment;
- Poly Haven CC0 materials plus selective rebakes.

Direct spend: **$40–$180** expected, excluding artist labor. Range assumes one paid environment pack, one or two low-cost prop/donor packs, and optionally one month of an AI 3D tool.

Manual work: **10–18 focused artist-days**.

Expected visual quality: **B+ / A-** for first-slice standard if top-down review drives revisions.

Delivery risk: **medium**. Paid environment/source access reduces cleanup surprises while custom hero work preserves identity.

Time to first playable visual slice: **~2–4 working weeks** full-time equivalent.

## 3. QUALITY-FIRST

Production mix:
- custom G-0 from approved concept;
- custom Cutter and Magnetar macro forms;
- Scout may still use a donor rig/legs after inspection;
- custom hero reactor and gate;
- paid high-quality industrial donor family used mainly for secondary architecture/props;
- dedicated retopo, bake, rig and LOD passes.

Direct spend: **$100–$400+** in assets/tools, excluding labor or outsourced modeling. If external specialist modeling is commissioned, labor can dominate this range by an order of magnitude and should be quoted separately.

Manual work: **18–35 focused artist-days** for one generalist, depending on review iterations.

Expected visual quality: **A- / A** relative to an indie mobile first slice, with the best uniqueness and continuity into later tiers.

Delivery risk: **medium-low for quality, high for schedule**. Main risk is iteration time rather than donor incompatibility.

Time to first playable visual slice: **~4–7 working weeks** full-time equivalent.

## Recommendation

Use **BALANCED** for the first slice. It spends money only where coherent environment sourcing saves real labor, while keeping identity-critical assets custom/hybrid. Do not spend heavily on stock character packs that still require near-total redesign.
