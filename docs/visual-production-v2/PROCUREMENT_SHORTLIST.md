## REJECT

- timgroote `spiderbot`: CC BY-ND; cannot be edited into required derivative production.
- AT-99 Scorpion: non-commercial license and uncertain uploader provenance.
- any unclear-license source after inspection.
- generic humanoid robots, military exosuits, box mechs, anime-mecha silhouettes.
- clean showroom/neon-everywhere sci-fi environment packs as final first-slice art.
- low-poly toy props as hero assets without a substantial production pass.
