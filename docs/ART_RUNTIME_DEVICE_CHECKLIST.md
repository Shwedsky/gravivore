Для Tier 0 нужен свежий профиль. При необходимости используйте существующую кнопку **DEV → Сброс профиля** (она удаляет прогресс на устройстве). Включите **Бессмертие** и несколько раз нажмите **+1 Мощность** или **+1 Все**, затем уничтожайте обычных врагов: Tier 1 включается на **20**, Tier 2 — на **42** очках ассимиляции. Каждое обычное убийство даёт 1 очко; счётчик виден в DEV. Повышение характеристик само по себе tier не меняет. Не нажимайте «Открыть элиту» до проверки Tier 1: эта команда поднимает ассимиляцию до 60. Cutter находится в **Cutting Floor, (0, 40)**; там четыре врага.

- [ ] 1. Игра запускается.
- [ ] 2. Видна более дальняя камера S20: offset (0, 14.8, −11.2), FOV 46.
- [ ] 3. Присутствует расширенная карта 72 × 140, с прежними зонами, элитой и боссом.
- [ ] 4. На свежем профиле правильно виден G-0 Tier 0.
- [ ] 5. Движение и повороты не разрывают модель; статические опоры для этого preview допустимы.
- [ ] 6. Gravity Lash начинается перед оружием, попадания и звук читаются.
- [ ] 7. На 20 очках появляется заметно другая форма Tier 1.
- [ ] 8. На 42 очках появляется заметно другая форма Tier 2.
- [ ] 9. Все Cutter используют новую V3-модель с красным ядром.
- [ ] 10. Движение, атака, попадание и смерть Cutter выглядят приемлемо.
- [ ] 11. Игрок и противник различимы с игровой дистанции.
- [ ] 12. Нет пурпурных материалов.
