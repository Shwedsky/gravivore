# Visual Replacement Proof V1

This folder is an isolated presentation proof and is intentionally not referenced by Chapter01.

## Run

Open `VisualReplacementProofV1.unity` in Unity 6000.3.0f1 and enter Play Mode.

The scene constructs first-party proof geometry, applies URP materials/lighting/post-processing, uses the mandatory portrait gameplay camera, and captures the requested ten PNGs plus measured mobile metrics to:

`Artifacts/VisualReplacementProofV1/`

## Boundary

Do not move these assets into production until the human owner reviews the generated gameplay-camera frames.

`PROOF_ONLY_AttackReadabilityProxy` and `PROOF_ONLY_DeathReadabilityProxy` are review-space/contrast proxies, not production VFX replacements.
