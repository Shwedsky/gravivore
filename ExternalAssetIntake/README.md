# External Asset Intake

For **new** external downloads use only:

`ExternalAssetIntake/Current/`

Raw third-party payloads are local/ignored unless explicitly safe to redistribute.

`ExternalAssetIntake/FreeAssetIntakeV1/` is a historical intake workspace retained only for reproducibility of the earlier V1/V2 acquisition pass. Do not add new assets there and do not use it as a current Codex source path.

See `docs/ASSET_SOURCE_OF_TRUTH.md`.
